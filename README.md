## Health Consumer Protection SPKO 2026 – Dual MC Script

### Dual MC Script

A dual MC script document for conducting the
**Capacity Development Project for the Health Consumer Protection Network on Health Products, Central Region Health Cluster, Fiscal Year 2026**

Samut Prakan Provincial Public Health Office

### Usage Information

* **Date:** 13–14 August 2026
* **Venue:** Rachatawa Room, Miracle Suvarnabhumi Hotel
* **MC 1:** Ms. Jittrawan Chantajitpricha
* **MC 2:** Mr. Saranyu Sotawong

### Features

* Displays the dual MC script in a web-based format
* Separates speaking parts by MC
* Allows text to be edited directly on the webpage
* Supports printing of the MC script
* Allows the edited MC script to be downloaded as an HTML file
* Accessible through a web browser

### Main Files

| File         | Description                               |
| ------------ | ----------------------------------------- |
| `index.html` | Dual MC script webpage and editing system |
| `README.md`  | System documentation                      |

### How to Use

Open the `index.html` file in a web browser.
Then select **“Edit Text”** to directly edit the script, names, or other details. Select **“Download Edited Version”** to save the edited version.
